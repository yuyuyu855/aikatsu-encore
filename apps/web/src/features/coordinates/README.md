# コーデ完成度の収録方針

`packages/catalog/data/coordinates.json` は公式カード裏面を目視確認した組み合わせを記録する。確認元の URL、SHA-256、掲載パーツ名を固定し、カード名は既存の検証済み表面ラベルと照合する。公式が必須カードセットを定義したという意味ではない。

完成条件は本アプリの定義で、裏面に掲載された同名コーデの専用パーツを各1枚以上所持すること。汎用アクセサリーはおすすめとして分ける。参考画面のアイスブルーは E1-05〜07 の3枚なので、裏面に掲載された E1-08「ジュエルつきパープルリボン」はおすすめに含め、分母に含めない。オーロラキス専用リボン E1-04 は完成条件に含む。レジェンダリールージュ裏面の同名専用ティアラ EP-002 は別の弾でも完成条件に含む。

現在は18組を確認済み。参考画面の17組という数字は完成条件の根拠として採用していない。E1-09/24/37/38/44/55/57/63/65 の裏面も確認したが、名称の異なる汎用パーツや別のコーデの靴を組み合わせる例なので、この同名専用パーツの集計には含めない。フルコーデ ER カードもこの複数パーツの集計から除く。収録範囲は partial とし、未収録を未完成や0組収録完了と誤認させない。

パラレル版の独立したカードIDと構成は現時点の公式取得データでは未確認。架空のIDや共通所持数を生成しない。将来追加する際は `variant: parallel` の別グループと別カードIDを登録する。完成判定はカードIDだけを使うため、同名の通常版とパラレル版を別々に数えられる。

選択した弾でグループを絞る。構成カードは完全なカード登録簿と全所持データから解決する。重複所持数、譲れる数、欲しい状態、おすすめカードは完成枚数を増やさない。Pages モードの画像表示は共有 `CardArtwork` を経由して公開方針に従う。
